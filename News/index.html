7-Zip heap overflow CVE-2026-48095 enables RCE via crafted NTFS images security Act Today Score: 10/11

A heap buffer overflow in the NTFS handler of 7-Zip v26.00 and earlier (GHSL-2026-140 / CVE-2026-48095, CVSS 8.8) allows attackers to execute arbitrary code via vtable hijack when a victim opens a crafted NTFS image. The bug stems from a 32-bit shift undefined behavior in CInStream::GetCuSize() that allocates a 1-byte buffer then writes 256 MB of attacker data. Users should update to 7-Zip 26.01 and avoid opening untrusted archives or disk images.
