Synology DSM: Exploited DSM flaw added to CISA KEV; two new advisories

CISA added an actively exploited Synology DSM flaw to its KEV catalog on Nov 18. The flaw is linked to ransomware, cryptomining and LLMjacking campaigns, but the report does not name the DSM CVE. Synology also released SA-26:21 (CVE-2026-120382, arbitrary file read/write in DSM and BeeStation OS) and SA-26:20 for NGINX2Root (CVE-2026-123007), the 10-year-old NGINX HTTP/2 flaw that can be chained to unauthenticated root.

Microsoft: November 2026 security updates

Microsoft calls all of these informational changes, and none is flagged as exploited.
