WordPress: Critical core path traversal flaw exploited for code execution

CVE-2026-87902 is a high-severity, unauthenticated path traversal flaw in WordPress Core. It allows PHP file inclusion and possible remote code execution. Attackers are actively exploiting it to write malicious files to disk. The fix is in 7.1.2, and fixes have been backported to branches 4.7 and later.

Windows + Server: Expiring Secure Boot certificates must be replaced

Microsoft is replacing 15-year-old Secure Boot certificates that expire in 2026. Devices that do not get the new certificates through Windows Update or OEM firmware updates will no longer receive security updates for the boot process. Affected systems include Windows, the ESU/LTSC editions, and Windows Server 2019, 2022 and 2025.

Microsoft 365 users: GhostCode kit uses device-code phishing to bypass MFA

A new phishing kit called GhostCode targets sales teams with fake business inquiries and WeTransfer links. AI-generated pages collect OAuth device codes, which lets attackers get around multi-factor authentication. The attackers then hold long-lived authentication tokens.

Windows + macOS: Fake CAPTCHA pages trick users into running stealer malware

A ClickFix campaign runs on hijacked legitimate websites and shows fake Cloudflare verification screens. Users who follow the steps install Psychedelic Stealer, which steals browser credentials and cryptocurrency wallets. A separate ClickFix campaign on macOS, Macfinger, uses shell scripts to deliver an information stealer.

Microsoft: September 2026 security updates

WordPress Elementor: CSRF flaw lets attackers create admin accounts

A cross-site request forgery flaw in the Elementor WordPress plugin lets unauthenticated attackers create administrator accounts. They do it by tricking a logged-in user into clicking a malicious link. Versions 4.3.0 and 4.3.1 are affected, and the fix is in 4.3.2.

Windows updates: Recent updates cause desktop loading and File History problems

Recent Windows updates (KB5120996, KB5120998 and KB5122880) cause black screens and Windows Explorer crashes on Azure Virtual Desktop hosts that use FSLogix. Microsoft has published manual workarounds and Known Issue Rollback policies. A separate bug from the September security update broke File History backups; the fix is in an optional preview update, and some sync issues may remain.
