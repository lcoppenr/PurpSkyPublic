Details

Microsoft 365: Stolen ConnectWise Cloud Backup app identities used against M365 tenants

Microsoft attributes the attack to the China-aligned group Storm-0940. The group used stolen ConnectWise Cloud Backup (formerly SkyKick) app identities to get around MFA, and used AI agents to try sign-ins at more than 2,250 M365 tenants. By October 16, unauthorized sign-ins were confirmed at 162 tenants, and some service principals gave themselves Exchange Administrator or Global Administrator rights.

Entra ID: Token replay campaign took over 79 organizations without passwords

Between July 14 and September 22, 2026, an attacker used adversary-in-the-middle relays to capture Microsoft 365 sign-in sessions and replay the stolen tokens, compromising 79 organizations. To keep access, the attacker registered at least 48 rogue devices in Entra and changed MFA methods. Huntress published the research on October 22 and notes that a password reset alone does not remove the attacker.

All users: Phishing sent as calendar invites gets past email filters

KnowBe4 reports Netcraft research showing attackers putting phishing content in calendar invite (.ics) files to get past email security filters. The malicious invites can show up in recipients' calendars even if the user never acts on the email itself.

WordPress / PHP: Apply php2shell patches and work around new unpatched flaw

PHP released patches for the php2shell flaws, and early exploitation has been reported. Days later, PHP disclosed a new code execution flaw, CVE-2026-115560, which affects non-default configurations and has no patch yet. Until a fix ships, PHP advises disabling session upload progress.

Microsoft: October 2026 security updates

Microsoft rescored the Windows Network Load Balancing remote code execution flaw CVE-2026-83862 from 9.8 to 8.8 after changing its attack vector from Network to Adjacent, so NLB hosts can be re-ranked for patching. The Win32 Kernel Subsystem elevation-of-privilege advisory CVE-2026-102208 changed only its acknowledgement. Neither entry reports exploitation in the wild.

UniFi Network: New releases revoke compromised eMudhra CA certificates

Ubiquiti released UniFi Network Application 11.0.97 and 10.6.109. Both revoke trust in compromised eMudhra CA certificates. Version 11.0.97 requires UniFi OS 6.0 or newer and also brings stability fixes, and the release notes do not mention exploitation.
