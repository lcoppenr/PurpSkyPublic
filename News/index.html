WordPress: Stolen UpdraftCentral keys used to plant backdoor plugins

Attackers breached TeamUpdraft around Oct 17–18 and used valid UpdraftCentral connection keys to install backdoor plugins on WordPress sites running UpdraftPlus. The backdoor creates a hidden Editor account that can escalate to admin, and Patchstack counted 99 backdoor plugin names in 18 hours on Oct 18–19. After updating, delete and reconnect keys, check for unknown admin accounts and plugins (including Must-Use plugins), and change passwords.

WordPress / PHP: Emergency PHP fixes for two critical PHP2Shell RCE flaws

PHP fixed CVE-2026-109618 and CVE-2026-109619, critical remote code execution flaws affecting nearly all PHP versions back to 5.4. Exploit attempts are active, an attempt was seen four days before disclosure, and SANS ISC raised its Infocon to yellow. Check distribution package changelogs for the CVE IDs, and be aware that the emergency patching may cause outages at some sites.

All users: Phishing tricks users into installing remote access tools

KnowBe4, citing Fortra research, warns of phishing campaigns that get victims to install legitimate remote monitoring and management (RMM) tools. Attackers then use that remote access to reach victims' bank accounts. There is no patch, because this abuses legitimate software; the defense is controlling which RMM tools are allowed and training users.

Synology DSM: PHP2Shell fixes for PHP packages, Calendar and Mail Station

Synology-SA-26:14 covers CVE-2026-109618 and CVE-2026-109619 (CVSS 9.8) in the PHP 7.3–8.4 packages, Synology Calendar and Mail Station. The fixed versions include PHP 8.4.27-0051 and 8.3.36-0051, Calendar 3.0.4-21435 and Mail Station 30000002.3.19-20333; PHP 7.3 is end of life and gets no fix. Synology rates the exploitation risk to the built-in OS PHP as very low because it is not exposed externally.
