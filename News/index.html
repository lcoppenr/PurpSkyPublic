Microsoft .NET: CISA confirms Brotli "Node2Shell" flaw is exploited in the wild

CISA added CVE-2026-111497, a critical out-of-bounds write in Google's Brotli decoder, to its Known Exploited Vulnerabilities catalog, which confirms exploitation in the wild. Microsoft has released an emergency .NET update for it and warns of privilege escalation; Node.js and HTTP servers and clients that use vulnerable Brotli code are also affected. Sources give different federal deadlines (November 10 per BleepingComputer, October 29 per SecurityAffairs).

Windows + macOS: Fake Cloudflare checks on hacked sites push ClickFix commands

On 2026-10-28 SANS ISC saw legitimate websites that had been compromised showing fake Cloudflare verification pages with ClickFix instructions for Windows and macOS users. Entra ID: SMS and voice MFA retirement starts February 1, 2027

Message Center post MC1528000 says Microsoft-provided SMS and voice authentication for Entra ID workforce tenants starts retiring February 1, 2027. Microsoft recommends moving users to passkeys or other phishing-resistant methods, and users enabled for SMS or voice will be asked to register a passkey at their next MFA. Tenants that need phone-based sign-in can set up a customer-managed telecom provider through the Microsoft Security Store.

Windows 11: Optional KB5127936 preview brings 41 changes, including cloud rebuild

KB5127936 is the optional, non-security October 2026 preview for Windows 11 25H2 and 26H2 (builds 26200.9818 and 26300.9818). It adds a faster, customizable File Explorer context menu, cloud rebuild (reinstalls Windows from Windows Update without USB media), WinRE reuse of saved Wi-Fi profiles and adaptive hibernate. Microsoft warns that some devices may restart one extra time after Secure Boot certificate updates, which replace the 2011 certificates that expire in late June 2027.

KnowBe4: Phishing up 29.8%; 41.3% gets past email gateways

KnowBe4's Phishing Threat Trends Report Vol. 8 says phishing volume rose 29.8% in 2026 compared with 2025, with one dangerous email in every 733 received.
