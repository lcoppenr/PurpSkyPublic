Microsoft: November 2026 security updates

Microsoft's update guide added or revised entries for remote code execution flaws in Remote Desktop Services (CVE-2026-108401), Windows SMB (CVE-2026-119988) and the Windows Codecs Library (CVE-2026-113749).
