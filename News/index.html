SonicWall TZ: Exploited SSL VPN MFA bypass added to CISA KEV

CISA added CVE-2026-19868, a SonicOS SSL VPN authentication bypass that gets past SAML/MFA, to its Known Exploited Vulnerabilities catalog with a federal deadline of November 20, 2026. SonicWall says the flaw is being exploited. It is one of seven flaws in advisory SNWLID-2026-0014 for Gen 7 and Gen 8 firewalls, including TZ models, and two of the others are CVSS 8.8 management-interface flaws.

Barracuda ESG: Two patched gateway flaws exploited to gain root access

Barracuda confirms that CVE-2026-116606 (a configuration-tampering authentication weakness) and CVE-2026-111560 (unauthenticated OS command injection as root) have been exploited against a small number of organizations. Exploitation requires access to the admin interface. Patches BNSF-40425 and BNSF-40430 install automatically by default, so customers who turned off auto-patching need to patch now.

Microsoft Edge: Chromium zero-day exploited in the wild; Edge fix pending

Google fixed CVE-2026-125350 in Chrome and says an exploit for it exists in the wild. It is the eighth exploited Chrome zero-day of 2026. Edge is Chromium-based, and the findings do not yet name a matching Edge build.

Synology DSM: Critical DSM SQL injection and 25 other fixes

Synology-SA-26:19 (Critical) fixes CVE-2026-76954, an SQL injection in the DSM Auth API (CVSS 9.8) that allows remote file read/write and denial of service, and CVE-2026-85101, an rsync authentication bypass (CVSS 8.6). Synology-SA-26:18 fixes 25 more DSM CVEs, eight of them rated Important. The deployed 7.3.2-86009-3 is affected, and no exploitation has been reported.

Apple: iOS, iPadOS and macOS updates fix iMessage and Bluetooth flaws

Apple's updates fix nine CVEs, including iMessage group-chat flaws (CVE-2026-113961, CVE-2026-113960) and Bluetooth/AirPlay pairing bugs that need no user interaction. iOS/iPadOS 27.2.1 also fixes the Brotli flaw CVE-2026-111497, which CISA added to KEV on Oct 27.
