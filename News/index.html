WordPress: Core race-condition RCE under active attack

Attackers are actively exploiting a high-severity (CVSS 8.1) WordPress Core flaw (GHSA-4w3m-c66w-69mg, no CVE), affecting versions 4.7 through 7.1.3. During a Core upgrade an unauthenticated attacker can win a race in the predictable wp-content/upgrade directory and run PHP code; Wordfence blocked 62,969 attempts in 24 hours. Fixed in 7.1.4 (released 2026-10-28); also check for suspicious requests under wp-content/upgrade and unknown admin accounts, plugins or PHP files.

Microsoft Teams: Fake IT help desk calls lead to full network takeover

Microsoft observed real intrusions that began with attackers posing as IT support over Microsoft Teams to get remote access. The attackers then abused Active Directory Certificate Services (ESC1/ESC8) to escalate privileges and steal data. Defenses are restricting external Teams contact and hardening AD CS configuration, not a single patch.

Microsoft Edge: About 51 Chromium fixes plus an elevation-of-privilege flaw

MSRC listed about 51 Chromium CVEs affecting Edge, mostly memory corruption and use-after-free bugs in V8, Skia, PDFium, ANGLE, SVG and WebRTC, plus a Brotli decoder buffer overflow (CVE-2026-111497). MSRC also published an Edge elevation of privilege flaw, CVE-2026-69446. None are reported as exploited in the wild.
