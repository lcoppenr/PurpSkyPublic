Microsoft 365: Stolen ConnectWise Cloud Backup credential used to enter 173 tenants

Attackers used a compromised credential for the ConnectWise Cloud Backup (formerly SkyKick) M365 app to get Microsoft Graph tokens, with unauthorized sign-ins confirmed in 173 MSP partner and customer tenants on October 15; in at least one tenant they granted a ConnectWise app Global Administrator and added credentials to other trusted apps. The campaign is active, ConnectWise has shut off app access, and revoking user sessions does not end the access. Review service principal sign-ins for App ID 506e08f9-6e9a-4da4-942b-a099a03644ae and IP 144.172.64.128, audit credentials and role assignments added since October 13, and turn on Graph activity logs.

Microsoft: October 2026 security updates

Microsoft revised October 2026 advisories across Windows, Windows Server, Office, identity components and .NET. Notable remote code execution flaws: Network Policy Server (CVE-2026-85806), Windows iSCSI (CVE-2026-70013), Remote Desktop Client (CVE-2026-32157), Outlook (CVE-2026-108448, CVE-2026-70291, CVE-2026-88156), plus many Word, Excel, PowerPoint, OneNote and .NET RCEs, and AD FS spoofing flaws. The findings do not report any of them as exploited in the wild.

Windows 11: KB5127648 can block re-enabling Smart App Control

After the October security update KB5127648, devices that had Smart App Control turned off may show the option grayed out and cannot turn it back on; devices that already have it on stay protected. It affects Windows 11 24H2, 25H2 and 26H2, and there is no permanent fix yet. Microsoft published a registry override for home users and a Feature Preview MSI plus Group Policy method for admins.
