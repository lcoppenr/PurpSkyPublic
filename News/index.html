Microsoft's September 2026 Patch Tuesday still breaking RDS on Windows Server 2019/2022/2025 -- Known Issue Rollback rolling out security Act Today Score: 10/11

Microsoft has confirmed the September 2026 cumulative updates are still causing RDS session hosts on Windows Server 2019, 2022, and 2025 to freeze hours after boot, leaving RDP connections stuck at "Connecting..." and blocking clean logoff -- directly impacting any RDP Gateway or session-host deployment. A Known Issue Rollback (KIR) is rolling out that reverses only the non-security regression while preserving fixes for CVE-2026-69525 (RDS RCE, CVSS 9.8) and CVE-2026-69518 (Remote Desktop clipboard RCE, CVSS 8.8). Deploy the KIR group policy on affected hosts rather than uninstall the update; this is a fresh remediation path beyond the KB5129238 OOB from last week.
