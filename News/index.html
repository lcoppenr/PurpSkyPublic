Azure CLI hit by LSHIY password spray -- 81M attempts, 78 accounts compromised via deprecated OAuth ROPC SECURITY Act Today Score: 10/11

A large-scale password spray campaign dubbed LSHIY targeted Azure CLI endpoints, generating over 81 million login attempts across 64 organizations and compromising 78 accounts. Attackers abused the deprecated OAuth 2.0 Resource Owner Password Credentials (ROPC) flow, which bypasses modern MFA and Conditional Access policies. Admins should audit for ROPC usage in sign-in logs, disable the legacy flow via Conditional Access or app-registration policy, and alert on unusual Azure CLI sign-in patterns — particularly relevant for your construction client's hybrid Entra tenant and your internal ops.

Entra Connect OnPremisesObjectIdentifier hardening enforcement live as of July 1 SECURITY This Week Score: 10/11

Microsoft is now enforcing a hardening change that blocks Entra Connect from modifying the OnPremisesObjectIdentifier attribute after it has been mapped to a synced user, closing a hard-match account-takeover technique. Audit logs now capture changes to OnPremisesObjectIdentifier and DirSyncEnabled, and a new Microsoft Graph API supports controlled remapping for legitimate recovery scenarios. Review Entra Connect sync error alerts at your construction client and internal ops, and use the Graph API rather than legacy workarounds when a remap is required.
