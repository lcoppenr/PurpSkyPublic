Windows users: Microsoft Store app caught delivering Vinci RAT

A threat actor published an app in the Microsoft Store that delivers Vinci RAT, which gives attackers remote control of infected Windows systems. The abuse is active in the wild. The report does not say whether the app has been removed.

Windows users: Official Q-Dir and DesktopOK installers trojanized with remote access malware

Attackers tampered with the Q-Dir and DesktopOK installers on the official SoftwareOK website so they delivered remote access malware. Anyone who recently downloaded these Windows utilities from the vendor site may have installed malware. The report does not say whether the files have been cleaned or which versions were affected.

Source 1 →

Windows Server: WSUS role removed from Windows Server 2028

Windows Server 2028, now in preview through the Windows Server Insider program and TAP, drops the WSUS role along with VBScript, WMIC and WINS. WSUS stays supported, with no new features, on Windows Server 2025 and earlier and can still manage updates for Server 2028. Microsoft recommends Windows Autopatch and Intune for clients and Azure Update Manager for servers, and says guidance for disconnected environments will come later.

ChatGPT: Chat and Work merging into one experience with shared usage meter

OpenAI has started rolling out a unified Chat and Work experience in ChatGPT to some users. An OpenAI spokesperson said Chat and Work will share a single usage meter, so heavy users may hit limits sooner. Some subscribers have criticized the change because it could restrict their usage.

OpenAI: GPT-6.2 Astra users will hit limits about 40% faster

OpenAI fixed a bug that had been under-counting GPT-6.2 usage. Because of the fix, users will reach their usage limits about 40% faster than before. This is a usage-accounting change, not a security issue.

Windows Server: Emergency hotpatch fixes Server 2025 crashes from November hotpatch

Microsoft released out-of-band hotpatch KB5138318 for Windows Server 2025 devices enrolled in hotpatching. The November hotpatch KB5131077 caused stop error 0x139 crashes on servers that have Router Advertisement enabled and receive time-bound IPv6 routes. The fix needs no restart, and Microsoft says only a limited number of servers are affected.
