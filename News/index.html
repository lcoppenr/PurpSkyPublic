Apple devices: CoreGraphics zero-day exploited in targeted attacks

Apple fixed CVE-2026-86950, an out-of-bounds write in CoreGraphics that allows arbitrary code execution when a malicious file is processed, and says it may have been exploited in an "extremely sophisticated" attack against specific targeted individuals. The fix is in iOS/iPadOS 26.7.1, macOS Tahoe 26.7.1 and macOS Sequoia 15.8.1. Devices already on iOS 27 / macOS 27 are not affected; the Sep 28 updates for those contain only functional changes.

Entra ID / Azure: Storm-3168 abuses stolen service principals to wipe Azure resources

Microsoft detailed Storm-3168, an actor linked to the JADEPUFFER ransomware operation, which used stolen Azure service principals and agentic AI automation to do recon, steal credentials and harvest keys, then deleted Azure storage and core resources within minutes. This is identity abuse seen in the wild, not a software flaw that can be patched.

AI accounts: Infostealers exposed AI logins at 80,000+ organizations

SOCRadar reports that infostealer logs exposed AI account credentials and sessions tied to more than 80,000 corporate domains. The risks range from stolen conversation history to LLMjacking, and the report points to shadow AI use as a growing problem for IT teams.

WordPress: Scans are probing for Wordfence-protected sites by IP address

Since Sep 28, SANS ISC sensors have seen requests for "wordfence-waf.php" sent to sites by IP address with minimal headers. The scans may be fingerprinting Wordfence-protected sites, or trying to get around the WAF by reaching sites directly by IP. ISC recommends patching the underlying software instead of relying on WAF virtual patching.
