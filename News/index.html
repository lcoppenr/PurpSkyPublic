Mac users: Fake Zoom installer drops CloudSyncD backdoor and steals passwords

Jamf Threat Labs found a fake Zoom installer that puts a macOS backdoor called CloudSyncD on the Mac. The installer also tricks the user into giving up their password. The report does not say whether there is a fix or how widely the backdoor is spreading.

Microsoft Edge: Three Chromium flaws fixed, in V8 and ANGLE

Microsoft's Security Update Guide lists three Chromium flaws that affect Edge: V8 type confusion CVE-2025-1920, V8 out-of-bounds read CVE-2025-2137 and ANGLE heap buffer overflow CVE-2025-10502. Edge gets the fixes through its Chromium updates. The listings do not say whether any of them is being exploited.

Microsoft 365: Fake Microsoft sign-in pages steal session tokens and get past MFA

A China-aligned group, TA419, is sending adversary-in-the-middle (AitM) phishing to U.S. AI policy experts. The pages copy the Microsoft sign-in page and capture both credentials and session tokens. This kind of phishing gets past MFA that is not phishing-resistant.

Claude: New opt-in setting for using voice data in model training

Anthropic added a Privacy setting that asks Claude users whether their voice conversation data can be used to train its models. It is off by default and can be changed at any time. It is separate from the existing training setting for chat and coding sessions.
