Synology DSM: Critical OAuth API flaw allows remote file read and write

Synology-SA-26:21 (CVE-2026-120382, CVSS 9.8) is a remote argument-delimiter injection flaw in the DSM OAuth API. It lets an attacker read or write arbitrary files and cause a denial of service. The affected range includes 7.3.2-86009-3 and -5. Fixes for DSM 7.3 (7.3.2-86009-6) and DSM 7.4 (7.4.1-90080-2) were scheduled for release by 2026-11-20. DSM 7.2.x users are told to move to 7.3.2-86009-6, and the advisory does not mention exploitation in the wild.

WordPress: Core 7.0.4 fixes Ghostscript-linked remote code execution

Researchers showed a Ghostscript sandbox escape that leads to remote code execution when apps process crafted uploaded files. WordPress is among the affected apps, and WordPress Core 7.0.4 fixes CVE-2026-65640. Ghostscript 10.08.0 fixes the underlying flaw, and the report does not say whether it is being exploited in the wild.
