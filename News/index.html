Details

Windows 11: 23H2 editions lose security updates in 30 days

Microsoft says some Windows 11 23H2 editions will stop getting security updates in 30 days, so devices on those editions need to move to a supported Windows 11 release. Separately, Microsoft says devices on unsupported Windows versions will stop receiving security updates after next year's Windows Update certificate rotation.

All users: Fake Claude installers spread through search ads

Attackers are buying Google Ads and abusing Bing redirects to send users to fake Claude installer pages that deliver ClickFix malware. The campaign is active in the wild. It is social engineering, so there is no vendor patch.

All users: Callback phishing extortion steals data without encrypting files

Silent Ransom Group is alleged to have extorted about $207 million, mostly from law firms, using callback phishing and data theft rather than file encryption. The defenses are user awareness and controls on remote-access tools, not a software patch.

WordPress: Bricksforge plugin flaw exploited for unauthenticated code execution

A CVSS 10.0 flaw in the Bricksforge WordPress plugin lets attackers run code remotely without logging in, and it is being exploited in the wild. The report does not say whether a fixed plugin version exists.

Apple iPhone: DarkSword iOS exploit kit adds wallet theft and remote commands

The P7 DarkSword exploit kit, which targets iOS, has added crypto wallet data theft and remote command features, which points to active use. The report does not name the affected iOS versions or say whether a patch fixes it. The latest Apple fix found was iOS/iPadOS 26.7.1 and macOS Tahoe 26.7.1, released in September.
