Microsoft 365: Device code phishing kit steals M365 access tokens

KnowBe4 analyzed a kit that starts a Microsoft device code authorization in advance and sends victims through a fake verification page to a genuine Microsoft sign-in. Approving it gives the attacker access and refresh tokens, which open Graph data such as email and files. KnowBe4 also recommends watching sign-ins for device code requests from the Microsoft Authentication Broker client ID and keeping AiTM detections active.

Windows + macOS: Fake AI-tool sites and CAPTCHA pages push "paste this command" malware

Researchers found 186 lookalike domains posing as AI tools that send users to ClickFix-style lures, browser-hijacking malware and malicious extensions; the campaign is active. A separate active campaign shows Mac users a fake CAPTCHA asking them to paste a command into Terminal, which installs the DownTheDRAIN infostealer. Both depend on the user running the command, so there is no patch.

Microsoft 365: Outage recovery uneven; some email still delayed

Microsoft incident MO1550821 began November 12 and left customers unable to reach Exchange Online, Teams, SharePoint Online, M365 Copilot and Defender XDR; Microsoft reports no sign of malicious activity. As of November 13 mail queues were close to normal and Microsoft had extended the email timeout window to 48 hours, but some users still saw intermittent access problems and delayed email. MSPs report recovery is uneven across tenants, and the outage also broke OpenAI and Anthropic connectors to M365.

Microsoft: November 2026 security updates

Microsoft added Microsoft Office to the update tables for several November CVEs, including a Windows Codecs Library remote code execution flaw (CVE-2026-113749), Graphics Kernel elevation-of-privilege bugs and an NTLM spoofing flaw (CVE-2026-121680). Windows updates also fix a Brotli decoder buffer overflow (CVE-2026-111497). The feeds give no exploitation status.

Microsoft Edge: 71 Chromium security fixes

MSRC ingested 71 Chromium CVEs (CVE-2026-125342 through CVE-2026-126922) for Edge, including use-after-free, type confusion and out-of-bounds write bugs. The fixes ship through Edge updates. The feed gives no exploitation status.

Windows Updates: November updates break activation and some printing

After the November updates, activation, KMS configuration and product-key commands fail with error 0x80041008 on Windows 10/11 and Server 2019/2022/2025; machines already activated stay activated, and Microsoft says a fix is coming "over the coming days". Separately, printing can fail for documents containing zero-size images (hidden watermarks or layout images), most often Word documents printed through GDI (tracked as WI1549472). Neither issue has a published workaround.

Windows CLFS: SignDrop zero-day exploit gives local users SYSTEM

A researcher released public proof-of-concept code that abuses the CLFS authentication feature to escalate a local user to SYSTEM, and reports say it can also bypass Windows Defender protections. It was tested on Windows 11 26H2, and 25H2/26H1 and Server 2025 with CLFS authentication are in scope. No in-the-wild attacks have been reported, and it is not in CISA KEV.

UniFi Network: 11.0.102 released; 10.6.111 fixes a backup restore bug

UniFi Network Application 11.0.102 is a new major version that requires UniFi OS 6.0 or newer, and upgrades from 10.x include a PostgreSQL-related change. 10.6.111 is a bug-fix release that fixes restoring backups from 9.0.120 and 9.0.122. Ubiquiti now recommends moving self-hosted deployments to UniFi OS Server.

Europol and partners in nine countries seized hundreds of servers and domains used by Gootloader, CastleRAT and StealC, which are used for initial access, credential theft and ransomware staging. Reports cite about 25,000 Gootloader infections and 6.4 million stolen logins seized.
