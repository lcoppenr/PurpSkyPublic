WordPress: Ninja Forms and WPC Product Bundles flaws exploited to hijack sites

Attackers are actively exploiting high-severity stored XSS flaws in Ninja Forms (CVE-2026-94504, since 2026-10-05) and WPC Product Bundles for WooCommerce (CVE-2026-93836, since 2026-10-04); both need authenticated access. The injected script runs when an administrator views the content and installs backdoored plugins and hidden admin accounts that survive removing the plugin. Fixes are in Ninja Forms 3.15.4 and WPC Product Bundles 8.6.7.

Exchange Online: EWS disabled by default this month unless an allow list is set

As part of the Exchange Web Services retirement, Microsoft will disable EWS by default in Exchange Online during October 2026 unless admins configure an AppID allow list. EWS shuts down permanently on April 1, 2027. Apps that still use EWS need to move to Microsoft Graph.

All users: New ClickFix tricks: fake Cloudflare checks and browser-cache payloads

More than 100 compromised websites show fake Cloudflare verification prompts that trick visitors into running commands that install the LunexStealer infostealer, per CERT-UA. A separate active ClickFix variant stores its payload in the browser cache to get around controls on what users can paste into the Windows Run dialog. There is no software patch; both rely on social engineering.

Dell PowerEdge: Critical Dell System Update flaw gives remote root

Dell System Update before 2.3.0.0 has a path traversal flaw (CVE-2026-86360, CVSS 9.6) that lets an unauthenticated remote attacker run code as root on PowerEdge systems running Linux or Windows. Version 2.3.0.0 also fixes four more flaws rated CVSS 7.3 to 8.2. No exploitation in the wild is reported.
