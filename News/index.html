WordPress: Core flaw exploited for remote code execution

CISA added CVE-2026-87902 (CVSS 9.2), a WordPress core flaw, to its Known Exploited Vulnerabilities catalog. Unauthenticated attackers can make get_page_template() include a local PHP file, which with some server and theme setups gives remote code execution; attackers are using pearcmd.php to do it. Versions 4.7.0 through before 7.1.2 are affected and the fix is in 7.1.2.

All users: ClickFix fake verification pages install password stealers

An active ClickFix campaign injects fake Cloudflare verification pages into hacked legitimate websites and tricks visitors into running commands that install Psychedelic Stealer, which takes browser and crypto credentials. On Macs, a new MacSync infostealer variant spreads through ClickFix and social-engineering lures, steals browser data and saved credentials, and adds a backdoor. SANS ISC also analyzed malware from the Macfinger ClickFix campaign.

WordPress Elementor: CSRF flaw lets attackers create admin accounts

A CSRF flaw in Elementor Website Builder 4.3.0 and 4.3.1 bypasses WordPress REST nonce validation, so a logged-in admin who opens one crafted link can let an attacker create a new administrator account. About 2 million sites run the affected versions. It was not known to be exploited when reported; 4.3.2 fixes it.
