Microsoft 365: Token replay campaign registers rogue devices and swaps MFA methods

Huntress disclosed an active campaign that combined adversary-in-the-middle phishing with token replay against Microsoft 365. Between July 14 and September 22 it produced at least 497 successful sign-ins and more than 200,000 failed attempts. Attackers registered at least 48 rogue devices in Entra ID, replaced victims' MFA methods and created inbox rules to hide messages.

Entra ID: Storm-0940 abuses stolen cloud app credentials against M365 tenants

Microsoft attributes a supply-chain compromise of ConnectWise Cloud Backup to the China-aligned group Storm-0940, which used the AI pentesting framework ARTEX against about 2,250 Microsoft 365 tenants and then used stolen cloud app credentials to get into customer environments without an interactive sign-in. Credentials the attacker added keep working after the ConnectWise connection is disabled, so defenders should review service-principal credential additions back to at least October 1. A separate report on the same group describes an automated password-spray campaign from October 10 to 14 against accounts where MFA did not apply.

Microsoft: October 2026 security updates

The most notable revised advisory covers a Windows Network Load Balancing remote code execution flaw (CVE-2026-83862). Its attack vector was corrected to Adjacent, so an attacker must be on the same network segment. Microsoft also corrected the fixed build number and download links for a PowerShell security feature bypass (CVE-2026-96303), which is worth re-checking against what is deployed, and updated the acknowledgements on a Win32k elevation-of-privilege advisory (CVE-2026-102208). None of these is reported as exploited.

WordPress / PHP: PHP2Shell fixes out; new unpatched PHP flaw has a workaround

The critical PHP2Shell flaws (CVE-2026-109618/109619) let an attacker without an account run code and are fixed in the October 21 releases. Exploit attempts have reached the millions, some trying to install a Mirai variant, but no successful exploitation has been confirmed. A separate new flaw (CVE-2026-115560) has no patch yet, and disabling session upload progress is the interim mitigation, which SANS also recommends because a bypass of the current fix exists.

UniFi Network: 10.6.109 revokes compromised eMudhra CA certificates

Ubiquiti released UniFi Network Application 10.6.109, which revokes trust in compromised eMudhra CA certificates. The private keys of eight eMudhra intermediate CAs turned out to be trivially guessable. Mozilla has distrusted the root, and Chrome plans to remove it on October 27.
