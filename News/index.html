Microsoft: October 2026 security updates

Microsoft re-released the September 2026 Exchange Server Security Updates as "V2" to fix CVE-2026-96940. This elevation-of-privilege flaw comes from weak authorization and can be exploited over the network by an authenticated attacker. It affects Exchange Server SE, 2019 CU14/CU15 and 2016 CU23; the 2019 and 2016 updates require Period 2 ESU enrollment. Microsoft has not said it is exploited in the wild. Known issues are HTTP 500 errors on published calendar (.ics) links and a deadlock affecting Korean-language mail.

Microsoft Edge: Chromium ANGLE heap buffer overflow fix listed for Edge

Microsoft's update guide lists Chromium CVE-2025-10502, a heap buffer overflow in the ANGLE graphics component that affects Chromium-based Edge. The entry does not say whether it is exploited in the wild. Edge gets the fix through its normal update channel.

WordPress: Backdoor reinstalls itself after cleanup

A WordPress backdoor keeps copies of itself in files, the database and shared memory, and reinstalls itself after a site is cleaned. Deleting the malicious files alone does not remove it. The report does not name an affected plugin, a core fix or how many sites are hit.

Exchange Online: EWS blocking for non-Microsoft apps starts this month

Microsoft begins a phased disablement of Exchange Web Services in Exchange Online in October 2026, which admins can control. Requests from non-Microsoft applications will be blocked, and full shutdown follows in 2027. Outlook for Windows/Mac, Teams and other Microsoft products are not affected.
