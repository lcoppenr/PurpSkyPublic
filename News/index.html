Microsoft 365: Attackers breaking into tenants via default-password service accounts

Attackers tried likely default passwords against 5,714 accounts across 28 Microsoft 365 environments and got into seven, six of them within seven minutes. The compromised accounts were unmanaged service accounts without MFA, and access extended to Office, OneDrive, Teams and SharePoint Online. The pattern points to shared or never-changed credentials on stale accounts.

Microsoft 365 Copilot: Admin deadline October 25 for agent and MCP package uploads

After October 25, 2026, users automatically gain the ability to upload declarative agents and MCP servers unless admins restrict it beforehand. Microsoft is also adding FinOps controls that limit which models a spending policy allows. Copilot in SharePoint and OneDrive is now generally available, with advanced features consuming Copilot Credits.

All users: Quote-request emails deliver Remcos RAT via Google Drive and Excel

AhnLab ASEC reports phishing emails posing as quote requests that drop VBScript and PowerShell and install the Remcos RAT from Google Drive. A related wave uses malicious Excel files exploiting the old CVE-2017-0199 Office flaw. Both campaigns are active in the wild.

Mac users: Fake Zoom installer drops a backdoor and phishes the Mac password

Jamf Threat Labs describes CloudSyncD, a macOS backdoor delivered through a fake Zoom installer that phishes the user's macOS password for elevated access. It spreads by social engineering rather than a software flaw, so there is no patch. The defense is installing Zoom only from official sources.

Windows 11: Optional preview update crashes apps using Dolby Digital audio

After the September 2026 KB5124010 optional preview update, apps and games that decode AC-3 (Dolby Digital) audio may close unexpectedly. Microsoft added the known issue to Windows release health on October 3, 2026. No fix is named yet. Affected builds are Windows 11 24H2/25H2 OS builds 26100.9550, 26200.9550 and 26300.9550.
