All users: Fake AI sites and ClickFix pages trick users into running commands

KnowBe4 reports that researchers at Island found nearly 200 typosquatted domains posing as AI brands such as Claude, ChatGPT, DeepSeek, Perplexity, Midjourney, ElevenLabs and Cursor, and that these domains deliver ClickFix attacks. In a separate active campaign, the ROMULUS ClickFix platform delivers a previously undocumented remote access trojan that can spy on users and control infected PCs.

Microsoft: November 2026 security updates

Microsoft listed a large batch of CVEs on 2026-11-19. The remote code execution flaws include Exchange Server (CVE-2026-55007), Outlook (CVE-2026-97749), Remote Access PPP EAP-TLS (CVE-2026-84015), .NET and .NET Framework, Office, Word, PowerPoint and more than a dozen Excel bugs. There are also elevation-of-privilege fixes for LSA, the SMB client, RRAS and other Windows components. The feed entries do not say whether any flaw is exploited in the wild.

PHP (WordPress): Critical PHP flaws, including remote code execution, fixed in new releases

PHP released security updates for critical flaws, including the "phpAfterShell" session bug (CVE-2026-126714), which can lead to remote code execution, plus an FPM local privilege escalation. A proof of concept has been shown for phpAfterShell, but exploitation in the wild has not been reported. The fixed versions are 8.2.36, 8.3.37, 8.4.28, 8.5.13 and 8.6.0.

Windows: Unpatched "FastUnlock" lock-screen bypass abuses Narrator

A researcher known as Chaotic Eclipse disclosed FastUnlock, a zero-day that abuses Narrator to start programs on a locked Windows PC without signing in. It needs physical access and gives only limited access. No fix is available yet.
