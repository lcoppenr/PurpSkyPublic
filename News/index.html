SonicWall TZ: Exploited SSL-VPN authentication bypass fixed in new SonicOS

SonicWall advisory SNWLID-2026-0014 fixes CVE-2026-19868, an SSL-VPN authentication bypass that affects services configured for SAML, plus six other SonicOS flaws. CISA added it to its Known Exploited Vulnerabilities catalog on November 6, and federal agencies must fix it by November 20. Affected versions are Gen7 7.3.3-7015 and earlier, and no workarounds are available.

WordPress: Exploited core flaw; the update itself can briefly expose sites

CVE-2026-119977 is a WordPress core race condition in the update staging folder that allows remote code execution. It affects versions 4.7 through 7.1.3 and is in CISA's KEV catalog, and Wordfence saw attack attempts on release day. Because the old code runs the update, sites are briefly exposed while updating, especially with complete-package updates on 5.9 and later. Versions 4.6 and earlier get no fix.

Barracuda ESG: Chained flaws give unauthenticated root access to the gateway

Researchers chained CVE-2026-116606, an authorization bypass that lets an unauthenticated attacker restore a crafted configuration backup (score 9.3), with CVE-2026-111560, a root command injection (score 8.6). Barracuda released patches this week. The flaws are not known to be exploited and no public exploit has been released. Until you patch, restrict the admin interface to trusted internal networks.
