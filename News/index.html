Microsoft Outlook: Exploited Outlook flaw leaks NTLMv2 hashes from crafted messages

CVE-2026-124194 (CVSS 6.5) lets a specially crafted message file make Outlook connect to an attacker-controlled location without the external-content warning, which can leak the user's NTLMv2 hash. Microsoft confirms it is exploited in the wild, and CISA added it to KEV with a federal patch deadline of 2026-11-24. The fix is in the November updates.

Barracuda ESG: Two patched gateway flaws now exploited to gain root

Barracuda says attackers are exploiting CVE-2026-116606 (CVSS 9.3 authorization bypass) and CVE-2026-111560 (CVSS 8.6 OS command injection as root) against a small number of organizations. The two can be chained for root access when the admin interface is reachable. The patches are BNSF-40425 for ESG 9.4.017 and later and BNSF-40430 for versions below 9.4.017.

Source 1 →

Apple devices: iOS, iPadOS and macOS updates fix a Brotli bug listed as exploited

Apple released iOS/iPadOS 27.2.1, 26.7.3 and 18.7.12 and macOS 27.2.1, 26.7.3 and 15.8.3, fixing nine CVEs. They include CVE-2026-111497, a Brotli decoder bug that CISA added to its Known Exploited Vulnerabilities catalog on October 27 (Apple's notes do not mention attacks), and two iMessage group-chat privacy flaws. Older devices such as iPhone XS/XR and iPad 7th gen did not get the iMessage fixes.

Synology DSM: Critical DSM flaw (CVSS 9.8) allows remote file read and write

Synology-SA-26:19 fixes CVE-2026-76954, an SQL injection in the DSM Auth API (CVSS 9.8) that lets remote attackers read and write arbitrary files, and CVE-2026-85101, an rsync authentication bypass (CVSS 8.6). There is no mitigation. The same releases also fix 25 more DSM CVEs from SA-26:18, and neither advisory mentions exploitation in the wild.

KnowBe4 analysts say attackers are moving social engineering into chat and collaboration platforms because users trust them more than email.

Microsoft: November 2026 security updates

This is one of Microsoft's largest releases, with source counts from about 1,090 to 1,260 flaws. It includes remote code execution fixes in Windows DNS, DHCP Server, Remote Desktop Services, Hyper-V, Windows Search, LDAP, Schannel and many Office apps. Only the Outlook flaw CVE-2026-124194 is reported as exploited. The updates also fix on-prem Exchange OWA sign-in and mail delivery broken by the October Windows Server updates (KB5131080/KB5131090), and Windows 10 ESU devices get KB5131096.

Apple iPhone / iPad: Public iOS sandbox escape lets apps read other apps' files

A sandbox escape published on GitHub lets a third-party app read files stored by other apps on iOS 26.7.1, 27.0.1 and 27.2, which could expose credentials and crypto wallet secrets. No attacks have been reported. Apple has not confirmed a fix, and it is unclear whether the 27.2.1/26.7.3 updates address it.

Windows 11: November update adds Explorer menu customization and Cloud rebuild

The November cumulative updates KB5132061 and KB5131087 add a customizable File Explorer context menu, a Cloud rebuild recovery option, WinRE reuse of saved Wi-Fi profiles, IPv6 CLAT support and wider memory integrity (HVCI) enablement. Microsoft warns that prompt-based DPAPI protection will be retired in April 2027. No known issues are listed, though one commenter reports install failures.

Microsoft Teams: Admins can limit who records and transcribes meetings

A new Microsoft 365 Roadmap item lets Teams administrators use meeting policies to restrict who can start recording and transcription. The roadmap also lists real-time call queue metrics in the Queues app on mobile.

When the organization restricts Default and Anonymous permissions, Outlook folder sharing will stop users from changing those settings. Other new roadmap items add visibility into recoverable items storage usage and A-Z subfolder sorting in Outlook on the web and new Outlook for Windows.
