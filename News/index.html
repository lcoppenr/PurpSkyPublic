Russian APT hijacks hotel Wi-Fi to steal Microsoft 365 tokens Security Act Today Score: 10/11

Security researchers report a Russian state-sponsored group compromising hotel Wi-Fi networks to intercept and steal Microsoft 365 authentication tokens from traveling executives. The campaign uses adversary-in-the-middle techniques against captive portals to bypass MFA and gain persistent access to Entra ID tenants. SMB users traveling for business are at direct risk.

Rails patches critical Active Storage flaw CVE-2026-66066 with RCE potential Security Act Today Score: 9/11

Ruby on Rails released coordinated patches (7.2.3.2, 8.0.5.1, 8.1.3.1) for CVE-2026-66066, a critical Active Storage flaw stemming from libvips 'unfuzzed' image handlers being enabled by default. An unauthenticated attacker can upload a crafted image, trigger variant generation, read arbitrary files including secret_key_base, and escalate to RCE. Apps handling user uploads should patch and rotate all readable secrets immediately.

CISA adds Cisco Secure Firewall Management Center zero-day CVE-2026-20316 to KEV Security Act Today Score: 9/11

CISA added CVE-2026-20316 to the Known Exploited Vulnerabilities catalog after reports of active zero-day exploitation of Cisco Secure Firewall Management Center (FMC). The flaw stems from static credentials for a low-privileged account that let an unauthenticated remote attacker log in and access sensitive data. Cisco FMC operators should apply the vendor fix and rotate credentials immediately.
