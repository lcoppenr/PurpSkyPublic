Details

WordPress: Rank Math PRO update carried a self-restoring backdoor

Copies of Rank Math PRO downloaded from rankmath.com or delivered as updates between 20:02 UTC on October 15 and 07:12 UTC on October 16 (version 3.0.123) carried malware that installs hidden backdoors able to rebuild themselves. The malware was used to take over websites. A clean 3.0.124 is out, and sites that installed and activated 3.0.123 should be treated as compromised.

All users: ROMULUS ClickFix platform tricks users into running malware commands

Forescout Research - Vedere Labs disclosed ROMULUS, a ClickFix delivery platform that tricks users into running malicious commands. Attackers are actively using it to distribute LegionLoader and other malware. It is a social-engineering technique, so there is no patch; user awareness and blocking script execution are the defenses.

iPhone + iPad: Apple lists nine more CVEs fixed in iOS/iPadOS 26.7

On October 19 Apple added nine fixed CVEs to the iOS 26.7 and iPadOS 26.7 security notes, including Baseband, Bluetooth (crash from radio range), Core Bluetooth (code execution from a paired device), Kernel, Messages and Wi-Fi. Apple does not mark any entry as actively exploited. Devices on 26.7 or later, which shipped September 14, 2026, already have these fixes.

Microsoft 365: Stolen ConnectWise app credentials used to reach M365 tenants

Attackers stole ConnectWise application credentials and used them to access customers' Microsoft 365 tenants. ConnectWise suspended Cloud Backup, took SaaS services offline, and on Monday said it had reset accounts, replaced application credentials and strengthened administrative-access protections. Cloud Backup remains offline with no restoration timeline given.
