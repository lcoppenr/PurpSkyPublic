Microsoft 365 Apps: Fix for blank dialog that blocks Outlook, Word and Excel

Some users saw a blank white dialog with no text or buttons that could not be dismissed, and it blocked Outlook, Word, Excel, PowerPoint, OneNote and Access. The fix is in Version 2611 (Build 16.0.20625.20142), released last week. Users who cannot update normally can force the update from an elevated command prompt with officec2rclient.exe and the update-to-version parameter.

Synology DSM: Critical PHP package flaws fixed (Synology-SA-26:22)

CVE-2026-129481 (CVSS 9.8) is a use-after-free in the PHP 8.3 and 8.4 packages, and CVE-2026-126714 is a session-file race condition that can be mitigated by setting session.upload_progress.enabled to 0. The fixed versions are PHP 8.2.36-0172 or later (DSM 7.2+), 8.3.37-0052 or later, and 8.4.28-0052 or later. The advisory does not say whether the flaws are exploited.

Windows: November updates break NTLM authentication with some third-party apps

Some devices fail NTLM authentication with third-party authentication proxies, SSO solutions and application packaging tools after the November updates, which start the first phase of NTLM message-signing changes (KB5135557). Microsoft has no fix yet. Its short-term workaround, which it may remove later, is the REG_DWORD ClientAllowUnsignedNtlm=1 under HKLM\SYSTEM\CurrentControlSet\Control\Lsa\MSV1_0; the long-term options are updating the product, moving to Kerberos, or getting an NTLM-compliant vendor update.

WordPress: Six WP Connect plugins backdoored; no patch, plugins closed

On November 22, 2026 a backdoor (CVE-2026-135202, CVSS 9.8) was added to six WP Connect plugins, including Air WP Sync 2.9.1-2.9.4 and WP Sync for Notion 1.7.4. It runs PHP code sent from a remote server and can leave webshells and WP-Cron hooks that stay after the plugin is removed. WordPress.org blocked the malicious versions before release, so sites are reported as unlikely to be affected, but no patch exists.

Entra ID: Connect Health API flaw exposed tenant metadata and admin emails

A flaw in the Entra Connect Health API, present from July 23 until a server-side fix on November 19, 2026, gave an unauthorized party read-only access to admin email addresses, tenant IDs, domain names and sync status. Microsoft says no passwords, tokens or keys were exposed, but warns the data could fuel targeted phishing or support-impersonation scams. It recommends phishing-resistant MFA and PIM for admins, its read-only PowerShell review script, and a review of Entra and Azure logs.
