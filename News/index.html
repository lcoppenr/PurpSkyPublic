All users: ClickFix "paste this command" lures spread through fake AI sites

Researchers found 186 domains posing as AI services. They send visitors to ClickFix social-engineering lures, malicious browser extensions or malware, and search hijackers. SANS ISC separately reports an active Mac campaign where a fake CAPTCHA tells users to paste a command into Terminal; it installs an infostealer that targets cryptocurrency wallets, and there is no patch because it relies on social engineering.

Microsoft: November 2026 security updates

SANS ISC counts 1,260 vulnerabilities in the November 2026 release, 68 of them critical; the Outlook spoofing flaw CVE-2026-124194 is the only one exploited. Remote code execution flaws are fixed in Exchange Server (CVE-2026-118207), Outlook, Word, Excel, Active Directory Domain Services (CVE-2026-118146), CredSSP, RPC Runtime, LDAP (CVE-2026-119958) and Microsoft Defender (CVE-2026-122194). The release also fixes the Brotli decoder buffer overflow in Windows (CVE-2026-111497) and 167 Chromium issues that affect Edge.

Windows: SignDrop zero-day grants SYSTEM; public exploit available

Researchers disclosed SignDrop, a Windows local privilege escalation zero-day in the CLFS driver that gives an attacker SYSTEM privileges. A public proof-of-concept exploit exists, and it can abuse Windows Defender to bypass security protections. The reports do not confirm whether the November updates fix it.

Windows updates: November updates break printing, activation and some installs

Microsoft confirmed that KB5132061 fails to install on Windows 11 26H2/25H2 devices that have the October preview update (errors 0x80070306, 0x800f0989, 0x800f0993). Microsoft also confirmed three other problems after the November updates: printing of documents with complex formatting may fail, Windows activation can fail with error 0x80041008, and SQL Server runs slower.
