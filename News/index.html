Windows 11 August update KB5063875/KB5063878 breaks AutoCAD first-launch for non-admin users Security This Week Score: 10/11

Microsoft's August Windows 11 security update KB5063875/KB5063878 blocks portions of the per-user MSI content configuration that AutoCAD, AutoCAD Toolsets, and Civil 3D (versions 2022-2026) run on first launch, causing an admin credential prompt for non-admin end users in enterprise deployments. This affects any customer who deploys AutoCAD centrally and lets standard users open it -- a common SMB pattern. Autodesk's forum announcement documents the workaround; expect end-user tickets until it is applied.

AmnesiaStealer macOS infostealer distributed via fake GitHub repos, grants live browser control Security This Week Score: 9/11

A new Rust-based macOS infostealer named AmnesiaStealer is being distributed via fake GitHub repositories impersonating legitimate projects. Unlike typical stealers, it gives operators live, interactive control over victims' authenticated macOS browser sessions -- cookies, saved credentials, session tokens -- enabling real-time account takeover of any logged-in site. Mac users who install unverified GitHub-hosted software are at highest risk; SMBs with Macs should reinforce EDR coverage and coach users to verify GitHub source repositories.
