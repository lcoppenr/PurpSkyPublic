All users: Calendar invites used to steal live sign-in sessions

Since mid-August 2026, a phishing operation has sent calendar invites to corporate users and used live reverse proxies to steal their Google sessions. It is built so that link-reputation checks come back clean. Because it steals live sessions, MFA alone does not stop it.

Microsoft: November 2026 security updates

November Patch Tuesday fixes roughly 1,090 to 1,260 CVEs, depending on the source, including an Outlook flaw exploited in the wild (CVE-2026-124194). It includes critical remote code execution fixes for Windows Server SMBv3, Remote Desktop Services, DNS Server and DHCP Server, plus Word and PowerPoint. Patch the SMB and RDS fixes first on internet-facing servers.
