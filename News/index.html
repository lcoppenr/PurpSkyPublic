Synology DSM: Exploited DSM flaw on CISA KEV, plus two new advisories

On Nov 18, CISA added an actively exploited Synology DSM flaw to its Known Exploited Vulnerabilities catalog and linked it to ransomware, cryptomining and LLMjacking activity. The reports do not name the CVE. Synology also released fixes for CVE-2026-120382 (SA-26:21), which allows remote file read/write and denial of service, and for the NGINX2Root flaw CVE-2026-123007 (SA-26:20). Neither advisory lists the fixed DSM build, so check each one against deployed 7.3.2-86009-3+.

All users: ClickFix "paste this command" attacks install a new remote-control trojan

Attackers are using the ROMULUS ClickFix platform, which tricks users into running commands themselves, to deliver a previously undocumented remote access trojan. The trojan can spy on users and take control of Windows PCs. The attacks are active in the wild.

KnowBe4 reports research from Island that found nearly 200 typosquatted domains impersonating AI brands, including Claude, ChatGPT, DeepSeek, Perplexity, Midjourney, ElevenLabs and Cursor. The domains deliver ClickFix social engineering attacks.

Microsoft: November 2026 security updates

MSRC revised advisories for remote code execution flaws in Exchange Server (CVE-2026-55007), Outlook (CVE-2026-97749), Excel (CVE-2026-118302 and about 15 related CVEs), Word (CVE-2026-69360 and others), Office and PowerPoint, .NET Framework (CVE-2026-70007, CVE-2026-70035) and Remote Access PPP EAP-TLS (CVE-2026-84015). Other revised advisories cover elevation of privilege in AD DS, LSA, SMB Client and Web Account Manager, plus denial of service in Kerberos and DNS Server. Most revisions only update acknowledgements, and none of the entries says a flaw is exploited.

WordPress: 7.0.9 and 6.9.12 fix SQL injection, XSS and an authorization bypass

WordPress 7.0.9 and 6.9.12 (Nov 18) fix a SQL injection tied to the Customizer front-page setting, several XSS issues, a REST API information disclosure and an authorization bypass affecting Author-level users. Windows: Unpatched "FastUnlock" lock-screen bypass through Narrator

A researcher released FastUnlock, a zero-day technique that abuses Narrator so someone with physical access to a locked Windows PC can start programs without signing in. The access gained is limited. No patch is available, and the sources do not report exploitation in the wild.
