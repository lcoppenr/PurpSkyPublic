Windows: Windows Shell zero-day exploited in the wild, now on CISA KEV

CVE-2026-96951 is a Windows Shell security feature bypass (CVSS 8.8). Attackers are using it to get around Mark of the Web, and the October 13 updates fix it. CISA has added it to its Known Exploited Vulnerabilities catalog, which confirms exploitation in the wild.

All users: Extortion groups pose as IT help desk over phone and Teams

ReliaQuest reports a surge in voice phishing and Microsoft Teams phishing in which extortion groups pose as IT help desks to gain initial access. KnowBe4 recommends user training and verification procedures for help-desk contacts.

All users: Fake AI-product lures spread malware and hijack business accounts

Attackers are posing as popular AI products to spread malware, steal browser sessions and take over business accounts at US companies. ANY.RUN linked 1,258 public sandbox analyses to the activity, which is active in the wild. There is no patch because this is social engineering.

All users: Business-themed phishing installs the MSP360 RMM tool for attacker access

Microsoft is tracking phishing campaigns that use business-themed lures to install MSP360, a legitimate remote monitoring and management tool. Attackers then use it to keep a foothold on compromised systems. There is nothing to patch; the defence is to allow only approved RMM tools and watch for unauthorized RMM installs.

Microsoft: October 2026 security updates

Microsoft fixed roughly 1,400 vulnerabilities on October 13, about 76 of them rated critical, including an actively exploited Windows Shell Mark of the Web bypass (CVE-2026-96951). Notable remote code execution groups include Excel (50), Remote Desktop Client (18), Word (15), DHCP Server (10), Windows DNS (9), Outlook (9) and Kerberos. A .NET Framework bypass (CVE-2026-108398) was publicly disclosed before the fix.
