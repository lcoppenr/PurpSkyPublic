All users: Fake Cloudflare checks trick users into running malware commands

CERT-UA reports that more than 100 compromised websites show fake Cloudflare verification prompts. The prompts use ClickFix-style tricks to get users to run commands that install the LunexStealer infostealer. The campaign is active in the wild.

AI tool users: Fake ChatGPT, Gemini and Claude pages steal logins and MFA codes

Malicious ads lead to fake portals for ChatGPT, Gemini and Claude that capture users' credentials and MFA codes. A separate phishing campaign offers a free "Claude Max" subscription as a lure to harvest Google account credentials.

All users: Tech support scams use Google Ads and fake browser alerts

Microsoft: October 2026 security updates

MSRC published remote code execution fixes for Windows Remote Access Connection Manager (CVE-2026-71343), Windows SSTP (CVE-2026-73009) and the Windows DHCP Client (CVE-2026-54128). It also published a Windows Defender Firewall Service security feature bypass (CVE-2026-61936), a batch of elevation-of-privilege fixes (Win32k, NTFS, GDI and others) and a high-severity on-premises Exchange Server flaw (CVE-2026-96940) that Microsoft rates "exploitation more likely." None are reported as exploited in the wild.
