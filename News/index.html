WordPress hosts: PHP2Shell remote code execution flaws now exploited

CISA added CVE-2026-109618 and CVE-2026-109619 (both CVSS 9.2) to KEV. Both are unauthenticated remote code execution flaws in PHP, and attackers are now exploiting them; the federal deadline is 2026-10-29. Fixes shipped 2026-10-21. On Windows, PHP also issued rebuilt packages (8.5.12-1, 8.4.27-1, 8.3.36-1, 8.2.35-1) with Brotli 1.2.1. Check for the "-1" build suffix or the SHA-256 hash, because `php -v` shows the same version.

.NET / Windows: Exploited Brotli "Node2Shell" flaw fixed in out-of-band .NET update

CISA added CVE-2026-111497, an out-of-bounds write flaw in Google's Brotli decoder (CVSS 9.2), to KEV on Oct 27 and confirms it is being exploited. It affects .NET 8, 9, 10 and 11 RC3 as well as Node.js, Python, PHP, curl and others. Microsoft released the .NET fix on Oct 25: Windows clients get it through Microsoft Update, Windows Server through WSUS or the Catalog. Affected processes must be restarted, and runtime updates do not change NuGet package references.

Microsoft Teams: Fake "IT Support" Teams chats lead to remote access and ransomware

Attackers flood victims' inboxes with email, then message them through Teams external chat as "IT Support" from throwaway onmicrosoft.com or .top tenants. They talk victims into granting access through Quick Assist, AnyDesk, ScreenConnect, TeamViewer, Atera or other RMM tools. They post no links, which avoids Safe Links and ZAP, and the payloads include backdoors and Chaos ransomware.

Microsoft 365: Device code phishing steals Microsoft 365 tokens without fake login pages

A campaign against US manufacturing, technology and healthcare organizations sends password-protected "contract" or "proposal" documents. These lead through sites.google.com into Microsoft's genuine device code sign-in flow, where victims approve a sign-in the attacker started. This hands over Microsoft 365 tokens with no stolen password, and the sign-in can look legitimate in identity logs.

All users: Real order emails from known brands carry callback scam numbers

Cisco Talos research, reported by KnowBe4, shows attackers abused more than 25 legitimate services over the past year to send phishing. Windows: Out-of-band updates distrust compromised eMudhra root certificates

Released Oct 26 for Windows 11 24H2/25H2/26H2 and Windows 10 21H2/22H2, these updates remove trust in seven eMudhra-related root and cross-sign certificates. Weak intermediate CA keys made forged website certificates possible. Admins should also find any certificates that chain to the removed roots.

Server firmware: 16-year-old UEFI PXE boot flaw allows code to run before the OS loads
