WordPress: Elementor CSRF flaw lets attackers create admin accounts

A high-severity cross-site request forgery flaw in the Elementor Website Builder plugin can let an unauthenticated attacker create administrator accounts once a logged-in admin clicks a crafted link. The reports do not say whether it is exploited or which version fixes it.

Entra ID: Attackers abuse compromised service principals to wipe Azure resources

Microsoft Threat Intelligence describes JADEPUFFER-linked activity, tracked as Storm-3168, that used compromised service principals for Azure reconnaissance, resource deletion and credential access. Reports say the actor deleted Azure storage within minutes and harvested keys; Microsoft's blog has detection and mitigation guidance.
