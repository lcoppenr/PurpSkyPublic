Details

All users: Fake Claude installers in search ads lead to ClickFix attacks

Attackers use malicious Google Ads and Bing redirects to send people searching for Claude to fake installer pages. Those pages use ClickFix social engineering to get users to run malicious commands themselves. The campaign is active, and user awareness is the main defense.

Microsoft: October 2026 security updates

On Oct 8–9 MSRC republished about 50 existing CVEs with acknowledgement-only changes. There are no new patches and no change to exploitation status. Notable remote code execution entries include Windows Netlogon (CVE-2026-72982), DHCP Server (CVE-2026-72979), DNS (CVE-2026-72987), DirectWrite, NTFS, Media Foundation, LLTD and iSCSI. None are reported as exploited.

Windows + Server: Older builds will lose Windows Update after 2027 certificate expiry

Windows Update certificates expire on May 17, 2027 and June 19, 2027, and devices that are not updated in time lose access to Windows Update. Server 2016 and 2019 need the July 2026 or later update before May 17, 2027. Win11 24H2 and Server 2025 need the September 2025 or later update, and other supported Win11 and Server 2022 need July 2026 or later, both before June 19, 2027. Win11 25H2 needs no action.

Apple iPhone + iPad: DarkSword exploit kit still infecting devices on older iOS

A new P7 variant of the DarkSword iOS exploit chain steals data from crypto wallets, iCloud Keychain, Notes and Photos, and it accepts remote commands. Censys saw live infections as recently as September 2026. It targets iOS 18.4 through 18.7. Attempts to extend it to iOS 26 failed, so devices on current iOS 26/27 are not reported affected.

Microsoft 365: China-linked group password-spraying M365 and Exchange accounts

The FBI says China-based Integrity Technology Group ran a portal that sold third parties access to stolen email, gathered partly by password-spraying Microsoft 365 and Exchange accounts. A joint advisory from seven countries came with the disclosure, and the FBI seized seven Flax Typhoon domains.

Defender for Office: Teams user reporting turns on by default October 25

Defender for Office 365 will turn on Teams user reporting of suspicious messages, calls and meetings by default on October 25, 2026, unless admins opt out. The settings moved to a dedicated Defender portal page on October 7, and changes may not display correctly until the week of October 15. It applies to tenants licensed for MDO Plan 1 or 2, M365 E5 or O365 E5.

Windows 11: October update arrives Oct 13; last quality update for 24H2

KB5124010 rolls out on October 13 for Windows 11 24H2, 25H2 and 26H2, and it is the last quality update for 24H2. New features include Copilot key remapping, an option to open apps maximized, better File Explorer previews and better Wi-Fi in WinRE. It also discontinues PC-to-PC Migration in Windows Backup.
