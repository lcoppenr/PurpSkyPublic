Microsoft: October 2026 security updates

Microsoft's October release fixes remote code execution flaws in Windows Network Policy Server (CVE-2026-85806), Windows iSCSI (CVE-2026-70013), Excel (four CVEs including CVE-2026-97776), Office (CVE-2026-78524), the Windows Raw Image Extension (CVE-2026-96202), .NET (CVE-2026-70197, CVE-2026-96237) and Power Apps (CVE-2026-70213). It also covers Schannel and AD FS spoofing flaws, a batch of Windows elevation-of-privilege flaws (Installer, Win32k, Update Service, MDM, RPC Runtime, VBS Enclave) and several denial-of-service flaws. Microsoft does not flag any of them as exploited.

Microsoft 365: Stolen ConnectWise app credential used to access 173 tenants

Attackers used a stolen ConnectWise application credential to sign in to 173 Microsoft 365 tenants. ConnectWise then suspended its Cloud Backup service and has not given a full fix or restoration timeline. Tenants that granted ConnectWise app access should check sign-in logs and app consents.
