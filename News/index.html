WordPress: Ghostscript upload chain enables remote code execution

Researchers showed that a Ghostscript use-after-free (CVE-2026-125396, CVSS 8.5) disables -dSAFER and allows remote code execution through crafted file uploads. WordPress Core is one route for users with upload rights, and the Forminator and Essential Addons for Elementor plugins are others. Both WordPress 7.0.4 (CVE-2026-65640) and Ghostscript 10.08.0 are needed because each fix covers a different part of the chain. The article reports no known exploitation.

Entra ID: Exploited Connect Health flaw exposed tenant metadata and admin emails

A flaw in the Entra Connect Health API, present from July 23 until a server-side fix on Nov 19, was exploited to read tenant metadata, including admin and technical contact emails, tenant IDs, license tiers and sync status. Microsoft says no passwords, hashes, tokens or valid keys were exposed, notified affected customers on Nov 20 and says customers do not need to fix anything. It recommends phishing-resistant MFA for privileged accounts and reviewing Connect Health configurations and audit logs, and it published a PowerShell script that shows which kinds of metadata could have been exposed.
