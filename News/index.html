Windows: November updates break some NTLM sign-ins; no permanent fix yet

The first phase of stricter NTLM message signing in the November 10 updates can make NTLM sign-ins fail for third-party authentication proxies, SSO tools and app-packaging software. It affects Windows 11 23H2 through 26H2 and Windows Server 2016 through 2025, and Kerberos is not affected. Microsoft listed it as a known issue in KB5135557 on November 20; the temporary workaround (ClientAllowUnsignedNtlm=1 under HKLM\SYSTEM\CurrentControlSet\Control\Lsa\MSV1_0) weakens security.
