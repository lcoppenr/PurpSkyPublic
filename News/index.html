Apple devices: Exploited CoreGraphics zero-day now has public exploit code

CVE-2026-86950 is an out-of-bounds write in Apple CoreGraphics. A malicious file can trigger it to run code, and Apple says it was exploited in targeted attacks. A public proof-of-concept is now available. Apple fixed it on 2026-09-28 in iOS/iPadOS 26.7.1, macOS Tahoe 26.7.1 and macOS Sequoia 15.8.1, and the iOS 27 branch is not listed as affected.

Exchange Online: EWS shutdown has started; Null tenants are being switched off

Microsoft began the phased retirement of Exchange Web Services in Exchange Online in October 2026, with a hard stop on April 1, 2027. Tenants whose EWSEnabled value is still Null on October 1, 2026 are changed to False as the rollout proceeds. This can break third-party apps and CRM/Outlook sync that rely on EWS.

Microsoft 365: CSuite phishing steals M365 sessions with fake sign-in prompts

A US-focused phishing operation called "CSuite" uses fake business documents and Microsoft sign-in prompts, including device-code phishing, to steal Microsoft 365 sessions. A second path installs legitimate RMM tools (ScreenConnect, Action1) for remote access. The campaign is active, and technology, manufacturing, government and consulting organizations are the most exposed.

All users: ChatGPT Custom GPTs used for ClickFix lures that install a RAT

Threat actors are using ChatGPT Custom GPTs to show ClickFix-style instructions that trick users into running commands. The commands install a remote access trojan. The campaign is active in the wild.

All users: Fake meeting invites and update prompts install remote access tools

Microsoft warned of active phishing campaigns that use meeting-invite and software-update lures to install MSP360 RMM. MSP360 then deploys ScreenConnect, which gives the attackers persistent remote access. There is no patch, because legitimate software is being abused, and the defense is to allow only approved RMM tools and alert on unexpected installs.
