WordPress: Core remote code execution flaw under active attack

Attackers began trying to exploit a high-severity remote code execution flaw in WordPress Core shortly after patches came out, with nearly 63,000 attempts logged in 24 hours. The flaw is being exploited in the wild, and a patched WordPress release is available.

All users: Fake ChatGPT and Claude desktop installers deliver a crypto miner

Yoba malware poses as the ChatGPT and Claude desktop apps. It uses signed installers and legitimate OpenAI and Anthropic binaries to sideload malicious code, then deploys a cryptocurrency miner. The main targets are users who download AI apps from unofficial sources.

Microsoft Edge: About 50 Chromium fixes plus an Edge privilege escalation flaw

MSRC added about 50 Chromium CVEs that affect Edge (CVE-2026-118304 through CVE-2026-118359, plus CVE-2026-91732). They are use-after-free and memory corruption bugs in V8, Skia, PDFium, ANGLE, SVG and other components, plus a Google Brotli decoder buffer overflow (CVE-2026-111497). MSRC also listed an Edge elevation of privilege flaw, CVE-2026-69446. None is reported as exploited.

ChatGPT: Shared links and Canvas flaws could expose chats or take over accounts

The Hacker News reports that opening a crafted shared ChatGPT link could run attacker code in the victim's session and expose private chats. Parameter Labs separately describes taking over ChatGPT accounts through the artifacts/Canvas feature, which appears to be related. Neither source says whether the flaw was exploited in the wild or whether it is fixed.

ChannelPro's roundup covers ConnectWise's response to a ScreenConnect-related incident. An attacker-controlled MDM tenant kept privileged access and could reinstall ScreenConnect after an MSP removed it. The advice is for MSPs to review trusted integrations, starting with their own tenant.
