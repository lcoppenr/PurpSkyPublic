WordPress: Core RCE flaw under mass attack; fixed in 7.1.4

A high-severity remote code execution flaw in WordPress Core (CVSS 8.1, no CVE) comes from predictable, web-accessible staging paths used during full-package core upgrades. An unauthenticated attacker can exploit it in a narrow race window while WordPress unpacks a Core update. Wordfence blocked 62,969 attack attempts in 24 hours. Versions 4.7 through 7.1.3 are affected, and 7.1.4 (released October 28, 2026) fixes it.

Microsoft Teams: Attackers pose as IT help desk in Teams chats

Microsoft describes intrusions where attackers posed as IT support in Microsoft Teams to get remote access and run malicious code. They then abused Active Directory Certificate Services through relay and Kerberos techniques (ESC1 and ESC8). This is an attack technique, not a single CVE, so there is no patch.
