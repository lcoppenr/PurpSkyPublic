Microsoft publishes registry workaround for Windows 11 KB5121003 gaming crashes security This Week Score: 9/11

Microsoft linked crashes, freezes, EXCEPTION_ACCESS_VIOLATION errors, and unexpected reboots on Windows 11 24H2/25H2 (KB5121003, Builds 26100.9168 / 26200.9168) to the inpoutx64.sys driver installed by RGB peripheral utilities. The temporary fix is to disable the driver by setting HKLM\SYSTEM\CurrentControlSet\Services\inpoutx64\Start to 4, or run sc stop inpoutx64 / sc delete inpoutx64 and remove the .sys file. Business fleet endpoints rarely run RGB software; any personal or shop-floor gaming rig on the workaround for now.
