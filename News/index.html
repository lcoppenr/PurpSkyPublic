WordPress: Critical remote code execution flaw exploited in the wild

Attackers are exploiting CVE-2026-87902, a critical WordPress flaw rated CVSS 9.2. Under certain theme directory conditions, an attacker without a login can include local PHP files and run code. Versions before 7.1.2, 7.0.6, 6.9.9 and 6.8.10 are affected.

All users: ClickFix fake error pages trick users into pasting commands

ClickFix campaigns show fake error messages or verification checks that trick users into copying malicious commands and pasting them into PowerShell or Terminal. The commands run through legitimate, signed system programs, so file-based and domain-based security controls miss them. Recent campaigns abuse trusted and hacked websites to deliver information-stealing malware.

A new phishing kit called GhostCode targets sales teams with fake business inquiries. AI-generated pages trick victims into entering device codes on genuine Microsoft sign-in pages. This hands attackers sign-in tokens and gets them past MFA.

WordPress Elementor: Flaw lets attackers create admin accounts

A CSRF flaw in the Elementor plugin lets attackers without a login create administrator accounts by tricking a logged-in admin into clicking a malicious link. Versions 4.3.0 and 4.3.1 are affected, and 4.3.2 fixes it.

Microsoft Threat Intelligence tracks Storm-2570, a ransomware affiliate that gets in through RMM tools including Atera and Splashtop. Before deploying ransomware, the actor often tampers with Microsoft Defender settings and registry values.

Windows 11: Recent updates cause black screens and Explorer crashes

Recent Windows updates (KB5120996, KB5120998, KB5122880) on 24H2, 25H2 and 26H1 are causing black screens and Windows Explorer crashes. The reports focus on Azure Virtual Desktop hosts that use FSLogix. Microsoft has a manual workaround through Task Manager and a Known Issue Rollback group policy.
