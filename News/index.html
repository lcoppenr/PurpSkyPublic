Microsoft: September 2026 security updates

MSRC revised several entries, including remote code execution flaws in Outlook and Word (CVE-2026-78510), the Remote Desktop Client (CVE-2026-32157) and .NET/Visual Studio (CVE-2026-69522, CVE-2026-71328), plus a Windows Secure Kernel elevation of privilege (CVE-2026-85921).
