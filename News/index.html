WordPress: Bricksforge plugin flaw exploited for unauthenticated takeover

Patchstack reports that attackers are exploiting a CVSS 10.0 flaw in the Bricksforge WordPress plugin, an add-on for the Bricks builder. The flaw allows unauthenticated remote code execution. Sites that use Bricksforge should update to the patched release or disable the plugin.

Windows 11: 23H2 Enterprise and Education support ends in 30 days

Microsoft says Windows 11 23H2 Enterprise, Education and IoT Enterprise editions reach end of servicing in 30 days, in mid-November 2026. After that date these editions get no more security updates. Devices should move to a supported release (24H2 or 25H2).

Source 1 →

Microsoft Edge: Six Chromium V8 engine fixes listed in MSRC guide

Microsoft republished six Chromium V8 CVEs in its Security Update Guide: CVE-2025-12727, -12441, -12433, -12432, -12429 and -12428. Edge gets these fixes from upstream Chromium. The entries do not say whether any of them are exploited.

UniFi Network: Version 11.0.83 moves to PostgreSQL and needs UniFi OS 6.0

Ubiquiti released UniFi Network Application 11.0.83, a new major version above the deployed 10.3+ line. It requires UniFi OS 6.0 or later and moves the database to PostgreSQL. The upgrade can take up to 20 minutes.

Microsoft 365: Work IQ agents will edit Office files and upload to M365

Two new roadmap items (570871 and 570850) say Work IQ agents will be able to update Office documents and upload files into Microsoft 365 storage. That gives agents write access to client data.

Microsoft Purview: SharePoint library default labels will apply to existing files

Roadmap item 575283 says Purview Information Protection will apply a SharePoint document library's default sensitivity label to files already in the library, not only to new or edited files. This can label older content in bulk.

Entra ID: Purview network DLP to cover all websites via Global Secure Access

Roadmap item 575285 says Purview network DLP policies will apply to all websites when traffic goes through Entra Global Secure Access Internet Access. Today coverage is limited to sanctioned apps; this extends it to general web traffic.
