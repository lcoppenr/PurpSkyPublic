Dell PowerEdge: Critical Dell System Update flaw gives remote attackers root

CVE-2026-86360 is a critical path traversal flaw in the Dell System Update (DSU) command-line deployment tool. An unauthenticated remote attacker can use it to run code as root. Dell fixed it in DSU 2.3.0.0, along with four more flaws: two allow remote code execution and two allow privilege escalation. No exploitation in the wild has been reported.

All users: Fake-invoice PDFs install Action1 and ScreenConnect remote access

SANS ISC reports phishing emails with fake-invoice PDFs whose links download MSI installers for Action1 or ScreenConnect. The attackers probably use free or trial accounts on the vendors' own cloud. There is no patch because this is abuse of legitimate tools. SANS recommends email controls, watching for suspicious service installs and blocking RMM tools you don't use.

Windows users: New ClickFix variant tricks users into running Run-dialog commands

Compromised websites save a malicious script in the browser cache, disguised as a PNG file. The user is then tricked into typing a short command into the Windows Run dialog, which starts a VBScript that finds and runs the cached payload. Recommended defenses are application control, PowerShell logging, hunting for RunMRU registry changes and user training.

Windows 11: Preview update KB5124010 crashes apps that use AC-3 audio

Microsoft confirmed that the optional September preview update KB5124010 can make some games, media players and productivity apps fail to launch or close without warning. The affected apps use Windows' built-in AC-3 (Dolby Digital) decoding, so older apps are most at risk. Microsoft is working on a fix but has given no timeline or workaround.
