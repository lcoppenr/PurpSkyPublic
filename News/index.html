Microsoft 365: China-linked group password-spraying M365 and Exchange to steal email

A joint advisory from the FBI and agencies in six other countries ties Integrity Technology Group, which is linked to Flax Typhoon, to password spraying against Microsoft 365 and Exchange with the EBurst tool. The attackers collected mail through Exchange Web Services (EWS) and office-cli, then used SoftEther VPN to stay in and DCSync to steal credentials. The activity is active in the wild, and the advised mitigations are MFA, conditional access and restricting EWS.

All users: Adobe-themed device code phishing pages hand attackers account access

ANY.RUN reports on Wazza, a phishkit that screens visitors through several stages before showing an Adobe-themed device code phishing page. Instead of only harvesting passwords, the page gets victims to complete an authentication step that gives the attackers access to the account. Targets include banking, government and manufacturing organizations in the US, EU and Australia.

Microsoft: October 2026 security updates

MSRC lists remote code execution flaws in Windows Netlogon (CVE-2026-72982, high-impact for domain controllers) and the Windows DHCP Server (CVE-2026-72979). It also lists RCEs in NTFS (CVE-2026-50448, CVE-2026-68875, CVE-2026-69566), Media Foundation (CVE-2026-62744), LLTD (CVE-2026-69732) and iSCSI (CVE-2026-69598), plus a Defender Firewall Service bypass and many elevation-of-privilege flaws. MSRC marks none of them as exploited in the wild, and the cloud-side flaws (Azure App Service, Bookings, Dataverse) are fixed server-side.

MSRC revised two Chromium V8 entries that apply to Microsoft Edge: an off-by-one error (CVE-2025-11215) and a use-after-free (CVE-2025-11219). Neither is flagged as exploited, and the fixes ship through Edge updates.

Windows Update: Outdated devices lose Windows Update after 2027 certificate rotation

Microsoft says devices on unsupported Windows versions will lose access to Windows Update when the update certificates expire on May 17 and June 19, 2027. Windows 11 25H2 needs no action. Windows 11 24H2 and Server 2025 need the September 2025 update or later, and other supported Windows 11, Server 2022 and Windows 10 builds need the July 2026 update before June 19, 2027. Server 2016/2019 and Windows 10 Enterprise 2019 LTSC need the July 2026 update before May 17, 2027, and devices updated through WSUS are not covered by this change.

Microsoft Teams: Deepfake detection and impersonation warnings coming in November

Teams will accept signals from certified third-party providers that check meeting audio and video for synthetic or manipulated content (roadmap 573451).
