Windows: Exploited Windows Shell zero-day bypasses Mark of the Web

CVE-2026-96951 is a Windows Shell command-injection and security-feature-bypass flaw (CVSS 8.8) that can get around Mark of the Web, and it is exploited in the wild. CISA added it to KEV with an October 16 federal deadline. The fix is in this month's Patch Tuesday updates.

WordPress: Bricksforge plugin flaw exploited for unauthenticated code execution

Patchstack reports in-the-wild exploitation since October 7 of CVE-2026-85097 (CVSS 9.8) in Bricksforge, a commercial add-on for the Bricks builder used on about 6,000 sites. Unauthenticated attackers can upload arbitrary files and execute code, and automated attacks are coming from distributed IPs. Versions 3.1.8.9 and earlier are affected; 3.1.8.10 fixes it.

All users: Extortion groups pose as IT help desk via Teams and phone

ReliaQuest, cited by KnowBe4, reports a surge over recent months in voice phishing and Microsoft Teams phishing in which extortion groups pose as IT help desks. The goal is initial access to corporate environments, and the activity is ongoing. There is no patch; the countermeasures are verification procedures and user awareness.

All users: Business-themed phishing installs legitimate MSP360 remote-access tool

Microsoft is tracking active phishing campaigns that use business-themed lures to install MSP360, a legitimate RMM tool, which attackers then use for a foothold. This is abuse of a legitimate tool, so there is no patch. Allowlist only approved RMM agents (Atera, Action1, Splashtop) and alert on any other RMM install.

Microsoft: October 2026 security updates

The record October release fixes about 1,413 vulnerabilities (sources count 1,412 to 1,417), more than 70 of them Critical. It includes the exploited Windows Shell Mark-of-the-Web bypass (CVE-2026-96951), a publicly disclosed .NET Framework WDAC bypass, 18 Remote Desktop Client CVEs and 13 RRAS CVEs. The products with the most CVEs are Windows Kernel, DNS Server, Windows Installer, Excel, SQL Server and AD FS; check RDP Gateway hosts against the MSRC update guide.

Windows: Researchers run code inside SmartScreen's protected enclave

Researchers showed code execution inside a protected Windows enclave used by SmartScreen by chaining a four-byte write primitive with a timing bug. That enclave is meant to stay isolated even when the rest of the system is compromised. The report does not say whether it is exploited in the wild or whether a fix exists.

Windows 11: October update is the last quality update for 24H2

The October 2026 Windows 11 update (KB5124010) is the last quality update for version 24H2, which reaches end of support. It adds an "open apps maximized" setting, more Copilot key remap targets, WinRE reuse of saved Wi-Fi profiles, and remote management support for MDM providers. The features roll out gradually through Controlled Feature Rollout.
