Microsoft: October 2026 security updates

About 39 Microsoft CVE entries were added or revised. They include remote code execution flaws in Network Policy Server (CVE-2026-85806), Windows iSCSI (CVE-2026-70013), Excel (CVE-2026-97776, CVE-2026-97777, CVE-2026-81396, CVE-2026-68798), Office (CVE-2026-78524), .NET (CVE-2026-70197, CVE-2026-96237) and the Windows Raw Image Extension (CVE-2026-96202), plus AD FS and Schannel spoofing and several Windows privilege-escalation flaws. None is flagged as exploited in the wild.

Microsoft Edge: 255 Chromium fixes, including six Edge RCE entries

Microsoft took in 255 Chromium CVEs that affect Edge (Chromium-based), along with six entries labeled Edge RCE. None is flagged as exploited. The latest Edge build applies the fixes.

Microsoft 365: ConnectWise supply-chain breach reached 173 M365 tenants

Attackers used a compromised ConnectWise credential to sign in to 173 customer Microsoft 365 tenants. ConnectWise suspended its Cloud Backup service and disabled seven application identities while it investigates. The investigation is ongoing and no customer-side fix has been named.

Autodesk AutoCAD: DWG files can hide orphaned VBA macro projects

A SANS ISC diary describes DWG drawing files that carry orphaned embedded VBA projects, which could hide macro code in files passed between project partners. It provides a YARA rule to detect them. This is detection guidance, not a vendor vulnerability, and there is no patch.
