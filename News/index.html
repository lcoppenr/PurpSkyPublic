WordPress: Core upgrade flaw exploited in the wild, added to CISA KEV

CVE-2026-119977 (CVSS 8.1) is a race condition in full-package Core updates. Because WordPress stages these updates on predictable paths that can be reached from the web, an attacker without credentials can run code. Wordfence logged over 18,500 requests aimed at staged setup-config.php paths in the first 21 hours. Patches came out in late October, and CISA gave federal agencies until November 6, 2026 to fix it.

Synology DSM: C3RB3R ransomware hitting NAS devices on outdated DSM

Synology warns that C3RB3R ransomware is attacking NAS devices on outdated DSM and encrypting files with a .L0CK3D extension. Synology's own advisory points to the 2024 flaws in SA_24_20, which are fixed in builds older than 7.3. Qihoo 360 says the gang also exploits CVE-2026-13684 and CVE-2026-13639, which were fixed in September 2026 under SA_26_13, but no affected versions are given for those two.

Microsoft 365: Device-code phishing and fake Teams help-desk calls target accounts

New device-code phishing kits (MadApe and the Skyw4lker campaign) use business-themed PDF lures and fake document-sharing pages to take over Microsoft 365 accounts. Microsoft also reported intrusions in which attackers posed as help desk staff on Teams and then used Quick Assist. Separately, M365 token-replay attacks compromised 97 accounts across 79 organizations.

Windows users: Fake cracked-software installers drop proxyware and adware

Microsoft Threat Intelligence describes a campaign that lures users into running trojanized installers. These install WorldProxyPool proxyware (kept running through SYSTEM-level scheduled tasks), BOINC with VirtualBox, and AW Manager/Windows Manager adware. Microsoft recommends cloud-delivered and tamper protection, ASR rules, and hunting for unexpected scheduled tasks.

Barracuda ESG: Chained critical flaws can give attackers root access

CVE-2026-116606 (CVSS 9.3) lets attackers bypass authorization without logging in and affects only Email Security Gateway. CVE-2026-111560 (CVSS 8.6) is a command injection flaw in several Barracuda appliances. Chained together, the two give root access, but the attacker needs access to the admin interface. No exploitation in the wild has been reported.

Patching: Microsoft says ~0.5% of disclosed flaws are ever exploited

Of roughly 383,000 vulnerabilities disclosed through September 2026, Microsoft links only about 2,000 to real-world exploitation.
